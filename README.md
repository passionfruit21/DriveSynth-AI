
# DriveSynth AI
### Synthetic Data Generation for Autonomous Driving Using Diffusion Models

DriveSynth AI is a college project exploring synthetic driving-scene generation using diffusion models and LoRA fine-tuning.

## Current Features
- React + Vite dashboard
- Synthetic driving-scene gallery
- Daytime, night, rain, and fog categories
- Dataset analytics and image comparisons
- FID evaluation results
- Generation Lab interface prototype

## Project Status
The dashboard is under active development. The Generation Lab
interface is available, but live model generation still needs
backend integration.

## Technology Stack
- React
- Vite
- Python
- Stable Diffusion 1.5
- LoRA fine-tuning

## Running the Frontend
1. Install Node.js.
2. Open a terminal in the `frontend` folder.
3. Run `npm install`.
4. Run `npm run dev`.
